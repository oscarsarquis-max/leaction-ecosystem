# Tokens e paleta

Extraídos dos logos:

| Token | Hex | Uso |
|---|---|---|
| `--panne-bege` | `#E5E4D6` | fundo |
| `--panne-bege-elevado` | `#F3F2EA` | cartões e tabelas |
| `--panne-grafite` | `#323334` | texto e cabeçalho |
| `--panne-sucesso` | `#2F5D3A` | conclusão |
| `--panne-atencao` | `#8A5A12` | atraso / espera |
| `--panne-erro` | `#8B2E2E` | bloqueio / cancelamento |
| `--panne-info` | `#2F4A5D` | execução |
| `--panne-foco` | `#1D4F73` | `:focus-visible` |

Auxiliares só para função. Estado também em texto/ícone. `prefers-reduced-motion` desliga animação.
