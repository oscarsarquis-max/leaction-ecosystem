# Permissões — custos e preços

| Código | Uso |
|---|---|
| `costing.read` | ler políticas, cálculos e comparações |
| `costing.policy.manage` | criar e publicar política |
| `costing.assumption.manage` | premissas e tarifas |
| `costing.calculate.planned` | previsto e padrão |
| `costing.calculate.actual` | realizado |
| `pricing.simulation.manage` | simular markup e margens |
| `pricing.review` | criar/aprovar rascunho de preço |
| `pricing.publish` | publicar ou retirar preço |

Padeiro, produção, gestor de produção e visitante **não** recebem essas permissões. Owner/admin recebem todas. Responsável técnico não publica preço. Comercial lê, simula, revisa e publica. Revisor regulatório só lê.
