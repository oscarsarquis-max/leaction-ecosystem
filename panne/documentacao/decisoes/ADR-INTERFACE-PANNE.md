# ADR — Interface da Panne

A primeira interface real é original, em React + TypeScript + Vite. Não copia menu, layout ou componentes do legado.

- Navegação principal horizontal
- Máxima área útil para o quadro (linhas densas, não Kanban)
- Paleta bege/grafite extraída dos logos
- Dados somente da API versionada de produção
- Ciclo de leitura: sem formulários operacionais completos
- Autorização visual a partir de `/api/v1/me`, nunca de grupos do IdP
