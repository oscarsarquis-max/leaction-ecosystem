# Glossário — chão de fábrica

| Termo | Significado na Panne |
|---|---|
| Demanda | Necessidade de produto (quantidade, data, estabelecimento), ainda sem ordem |
| Plano | Agrupamento de demandas de um recorte (data, turno, estabelecimento) |
| Ordem | Compromisso de produzir um produto com versão e escala congeladas |
| Batelada | Unidade executável da ordem (uma masseira, um forno, um ciclo) |
| Snapshot | Cópia congelada da formulação/escala no ato da liberação |
| Planejado | Quantidades e etapas no snapshot |
| Realizado | Consumo, tempos e rendimento apontados |
| Separação / pesagem | Conferência dos materiais planejados antes ou durante o início |
| Apontamento | Registro de fato (consumo, resultado, ocorrência) |
| Ficha impressa | Projeção papel da ordem/batelada, mesma fonte do digital |
| Quadro | Projeção visual das ordens do recorte operacional |
| Relatório | Projeção posterior sobre eventos; não é cadastro |
| Trial | Ensaio de laboratório; **não** é ordem |
| Estação | Ponto de trabalho (mesa, masseira, forno) |
| Turno | Recorte temporal combinado com data |
