# Prompts

Área destinada a prompts versionados usados no desenvolvimento e no produto.

Cada prompt deverá informar finalidade, entradas, formato de saída, limites, exemplos de teste, versão do modelo quando relevante e critérios de avaliação. Prompts não deverão conter segredos, dados pessoais reais ou textos normativos sem autorização.

Arquivos de sprint poderão seguir o padrão `sprint-NN-descricao.md`.
