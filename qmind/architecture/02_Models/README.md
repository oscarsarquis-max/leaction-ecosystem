# Modelos

Área destinada a modelos de domínio e modelos de avaliação, como estruturas de maturidade, critérios de pontuação, taxonomias de constatações e esquemas de saídas de IA.

Todo modelo deve registrar versão, responsável, finalidade, critérios, limitações e histórico de mudanças.
