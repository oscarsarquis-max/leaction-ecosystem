# OI public contract snapshots (v1)

Cópias dos JSON Schemas públicos do QMind OI usadas pelo check de compatibilidade do Core.

Fonte de verdade: repositório `qmind-oi` (`schemas/v1/` via `qmind-oi-export-schemas`).

Atualizar:

```powershell
python scripts/sync_oi_contract_schemas.py
python scripts/check_oi_contract_compatibility.py
```

Não importam o pacote Python `qmind_oi`.
