# Spider integration — blocked in the foundation

ActionFinance is a candidate EXPERIENCE satellite. This folder documents the boundary. It does not contain an HTTP client, mock provider or permissive adapter.

| Item | Foundation state |
|---|---|
| Satellite Contract financial version | Not chosen |
| Registration in Spider | Not requested |
| Health calls to Spider | Not required and not made |
| Payload / webhook | Forbidden |

Local operations (system info, demo access, readiness of the own database) do not create a canonical Spider execution.

Panne remains the source of operational facts. Those facts may later originate obligations in ActionFinance when a contract exists. No Panne title API is assumed.

See `ACTIONFINANCE_INT_001` and the preliminary `backend/src/main/resources/satellite-manifest.yaml` (`executable=false`, `acceptedBySpider=false`).
