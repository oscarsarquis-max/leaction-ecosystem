# Serviços auxiliares

Pasta reservada para integrações externas e processos de apoio (fila, webhooks, workers) quando existirem.

Nesta etapa **não há** microserviços, workers nem contêineres extras. A API HTTP vive em `backend/`. Chamadas do browser ficam em `frontend/src/services/` e não devem ser colocadas aqui.
