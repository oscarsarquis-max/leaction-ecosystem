# Prompt 81 — Referências especializadas (prévia editorial)

Flag pública: `LOJADEPAES_GIGIO_PAIRING_REFS_ENABLED=false`.
Alegações especializadas **não** estão ativas até revisão e publicação explícitas.

## Quem é dono de cada dado

| Dado | Dono | Onde editar |
|---|---|---|
| Síntese, fonte, escopo, estado editorial | Loja | `/admin/produtos/gigio/harmonizacoes` |
| Explicações de pão/fermentação | Loja | `/admin/produtos/gigio` |
| Oferta, natureza, preço, link comercial | Hub | curadoria do marketplace |
| Pães, fotos, receitas, associações da vitrine | Loja | vitrine / receitas / complementos |

Não há segundo catálogo de ofertas nem agente novo. `pairing_tips` continua sendo dica de ingrediente da receita — outro objeto.

## Correspondência (sem excelência por preço)

1. Natureza correta (eliminatório; salame ≠ queijo).
2. Compatibilidade de perfil (hints verificáveis no anúncio).
3. Completude dos dados.
4. Aprovação editorial (`Escolha de A Loja`) só com revisão registrada.

Estilo/região não certifica SKU nem safra. Comissão e mais vendidos não entram no juízo.

## Base inicial (rascunho)

Cinco sínteses originais, consultadas em 2026-10-07:

1. Tinto do Dão + leitão — Evino blog (comercial).
2. Estilos para porco no churrasco — Evino blog (comercial).
3. Harmonização por página de produto — Evino ajuda (método, comercial).
4. Queijo Canastra IG201002 — INPI (independente).
5. Caracterização de azeite extra virgem BR — Embrapa (independente).

Nenhuma está publicada. Nenhuma é «Escolha de A Loja». Não há parceria Evino nem certificação de sommelier.

## Jornada

Pergunta → (se flag + publicado) poucas referências → resposta → «Para completar a mesa…» se couber → CTA da vitrine. Fontes em «Sobre esta sugestão», separadas do botão comercial.

## Limitações desta entrega

- Sem crawler, sem pesquisa aberta por conversa, sem API Evino.
- Sem nota numérica de excelência.
- Produção deve permanecer com a flag desligada até o proprietário revisar e publicar.
- Prompt 80 (fotos, títulos, CTA de mesa) não depende desta base.
