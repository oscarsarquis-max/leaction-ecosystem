# Seeds — política futura

Esta pasta reserva o espaço para dados de desenvolvimento controlados.

Regras:

- seeds só entram depois de um contrato de dados aprovado;
- não incluir nomes, documentos, e-mails, telefones ou qualquer dado pessoal;
- não usar exemplos que possam ser confundidos com clientes, apólices ou sinistros reais;
- não popular tabelas de negócio nesta fundação — elas ainda não existem;
- qualquer seed futuro deve ser reproduzível, explícito e descartável.

Nenhum arquivo de dados é versionado nesta etapa.
